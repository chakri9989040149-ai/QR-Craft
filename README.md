# 📱 QR-Craft: QR Code Generator

A modern, lightweight, and user-friendly application designed to create custom QR codes in seconds. Whether you are sharing a website link, setting up guest Wi-Fi access, or encoding plain text, this tool delivers clean, high-resolution QR codes instantly.

---

## ✨ Features

* **Multiple Formats:** Generate QR codes for URLs, plain text, email addresses, phone numbers, and more.
* **Instant Rendering:** See your QR code update and generate in real time as you type.
* **Easy Export:** Download your generated QR codes instantly for use in projects, print, or sharing.
* **Responsive UI:** Fully optimized for smooth usage across desktop and mobile devices.
